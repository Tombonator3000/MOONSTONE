Effects

The game is drawn in layers: background, figures and text separately. The effects use that.

HD graphics

With HD on, photographic standard graphics load automatically: backgrounds, the blue knight walking, knight selection, the menu pointer and moon phases. Other animations still use the original graphics. You can also pick your own HD images.

Backgrounds: save the one on screen, redraw it at a higher resolution and put it in the bg folder of the HD pack with the same name.

Online game

Moonstone has two joystick ports. Joystick 1 (port 2) is used on the map; in a fight between two knights both are used. Players on the same joystick share it like at a real table: whoever has the turn is in control.

Game file and your own files

The game file (Moonstonecd32-AMIGA.zip) is built into the page. To use another one, such as “Moonstone CD32.iso”, choose it here. Guests in online games don’t need a game file.

Files made with tools/gfx.py build (such as bg1a.PIV) replace the originals in data/, and tekster.txt from tools/tekst.py changes the texts in the game. They are used when the game restarts. In online games, guests get them from the host.

No files of your own.

Controls

  • Intro: Esc, fire, Enter or a tap on the screen skips it.
  • Game menus: click or tap an item, or use the arrow keys and Enter (or fire).
  • Choices on the map (fire on a location): tap a choice below the picture, use the d-pad and Fire, or the keys 1-9.
  • Mouse: outside the menus the left button is fire. Hold it and drag for fire plus a direction (the attacks in battle). Right button and drag is direction only.
  • Online play: choose Options and Online Game in the game menu.
  • Controls: the keys and buttons below can be changed in the game menu under Options (Keyboard and Gamepad). The list shows the defaults.
  • Joystick 1: arrow keys, Ctrl is fire. Gamepad 1.
  • Joystick 2: keypad 8 2 4 6 (7 9 1 3 diagonally), 0 is fire. Gamepad 2.
  • Space: the knight’s inventory. E: end your turn.
  • In battle: hold fire and press a direction for the eight attacks (see the manual).
  • Home: this menu. Page Up / Page Down: save / load. End: next save slot. F10: restart.
  • On a gamepad: A = fire, B = space, Start = E, Back = Esc, LB RB X Y = 1 to 4.

Moonstone: A Hard Days Knight (Mindscape 1991), running the original code on an emulated Amiga 500. The core is written in C (WebAssembly), the picture is drawn with three.js and online play uses PeerJS. The menu uses the game’s own font and graphics.
